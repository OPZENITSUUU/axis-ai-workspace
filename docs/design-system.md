# AXIS Design System

## Verified visual direction

AXIS uses a calm premium personal-workspace aesthetic. The desktop layout combines a deep charcoal conversation sidebar with a warm off-white reading surface. A restrained lime accent signals primary actions and assistant intelligence without overpowering the interface.

## Color and hierarchy

| Element | Visual treatment |
|---|---|
| App shell | Warm off-white workspace surface |
| Sidebar | Deep charcoal to create visual focus and persistent navigation |
| Primary action | Soft lime button for “New chat” and assistant marks |
| Primary text | Near-black editorial heading treatment |
| Secondary text | Muted gray for instructions and metadata |
| Cards/composer | White rounded surfaces with subtle borders and shadows |

## Typography and layout

The design pairs an editorial-style display serif for the central prompt with a clean sans-serif for navigation, controls, conversation labels, and message composition. Spacing is deliberately generous; the central content column remains narrow enough for focused reading and the composer is visually anchored near the lower section.

## Responsive behavior

Desktop uses a fixed conversation sidebar. At mobile width, the sidebar collapses behind a compact menu control, while the central prompt, suggestion cards, and composer retain clear hierarchy and touch-friendly spacing.

## Validation

The unsigned/empty-state layout has been visually checked at 1280×720 and 375×812. Both views preserve legible contrast, visible controls, and a stable layout without horizontal overflow.
